## Windows

### 账号与数据源

- 新增账号与数据源选择能力，支持在不同额度来源之间切换并清晰展示当前来源状态。
- 优化 OAuth 额度展示、账号状态反馈和退出登录确认流程。
- 改进设置中的来源交互和状态同步，减少切换后界面状态滞后的情况。

### 刷新与额度一致性

- 优化数据源切换后的额度重新加载和刷新协调，确保切换后能及时得到对应来源的数据。
- 改进刷新状态反馈、额度窗口加载和统计页面之间的一致性。
- 保留待处理的官方用量数据，提升刷新过程中额度与统计信息的稳定性。

### Token 统计

- 持久化本地 Token 使用记录，提升重启和后续查看时的统计连续性。
- 改进分叉会话的 Token 计量回放，并在局域网数据暂不可用时保留已有统计信息。
