## Windows

### 窗口布局与主题

- 改进额度和 Token 页面弹窗的初始布局与动态尺寸计算，修复首次打开、内容变化及不同 DPI 缩放下窗口尺寸不准确、内容裁剪或留白的问题。
- 修复浅色、深色及高对比度主题下界面颜色资源和视觉状态的解析与刷新，系统主题切换后额度、Token 热力图和托盘图标保持一致。

### 安装器与登录引导

- 改进首次使用时的 OAuth 登录引导；在无法读取额度且未连接账户时提供前往设置登录的入口，OAuth 登录成功后自动切换额度来源。
- 改进 Windows App Runtime 的准备和安装失败恢复：支持使用安装器旁的同名运行库文件，显示可取消的下载进度，失败时提供重试和 Microsoft 官方下载入口，并在校验与安装完成后复检运行库状态。
