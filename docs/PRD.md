# CodexQuotaTray 产品需求

## 用户问题

Codex 用户需要在不打开官方 Usage 页面、不打断当前工作的情况下，快速了解：

- 当前有哪些额度窗口；
- 每个窗口还剩多少额度；
- 每个窗口何时重置；
- 当前可用重置卡数量及已知到期摘要；
- 数据是最新、刷新中、过期、离线还是不可用。

用户不应为了查看额度而交出浏览器 Cookie、复制认证信息，或承担应用误执行账户写操作的风险。

## 产品目标

- 提供轻量、低干扰的 Windows 托盘额度查看体验。
- 使用本机 Codex App Server 提供的官方只读数据，不抓取网页或自行估算额度。
- 准确表达缺失、未知、部分可用和读取失败，不把未知值伪装成零。
- 刷新失败时保留最后一次有效数据，并清楚标记其可靠性。
- 让刷新、提醒、显示和缓存行为可由用户控制。
- MVP 始终只读，不消费重置卡，不执行账户写操作。

## 用户可见行为

### 托盘与面板

- 应用常驻通知区域，左键打开或切换额度面板。
- 托盘右键菜单只提供打开面板、设置和退出。
- 面板按服务端实际返回的窗口数量动态展示，不固定假设 `primary` 或 `secondary` 对应某个周期。
- 每个窗口显示名称、剩余或已用百分比、进度、重置时间和倒计时。
- Tooltip 使用当前运行身份的名称，并附带最多两个额度窗口摘要和状态。

### 状态和刷新

- 用户可以识别成功、刷新中、部分数据不可用、过期和读取失败状态。
- 手动刷新、定时刷新、服务端通知、窗口打开、睡眠恢复和网络恢复进入统一协调流程。
- 任意时刻最多进行一次主动额度读取；失败采用有界退避。
- ManualOnly 模式不发起自动读取，但仍可接收并安全合并服务端通知。
- 读取失败不得清空最后一次有效额度快照。

### 重置卡

- `rateLimitResetCredits.availableCount` 是可用重置卡数量的权威来源。
- 字段存在且有效时，应用展示数量；数量为零时明确展示零张。
- 明细可用时，应用展示最早已知到期时间或部分明细摘要。
- 只有数量而没有可靠明细时，应用只展示数量并说明到期时间未提供。
- 字段缺失或无法可靠解析时显示不可用，不显示为零。
- 不从通用 credits 余额、明细数组长度、opaque ID、网页或历史数据推测数量。

### 设置、缓存和提醒

- Production 可配置当前用户开机启动和静默启动；Preview 与 Demo 不允许配置 Production 启动项。
- 支持刷新模式、网络恢复刷新、剩余/已用显示、时间格式、主题和额度缓存设置。
- 支持剩余 50%、20%、10% 阈值提醒及额度周期重置提醒。
- 首次有效快照只建立提醒基线；同一窗口、同一周期、同一阈值最多提醒一次。
- 非敏感缓存可关闭和清除；缓存只作为最后已知数据，不能替代实时读取。

## 功能范围

- Windows 10/11 x64 托盘应用。
- 动态额度窗口规范化与展示。
- 重置卡数量和已知到期摘要的只读展示。
- 自动、固定间隔和仅手动刷新模式。
- 服务端稀疏通知合并、失败保留和状态投影。
- 设置、非敏感额度缓存和提醒防重复状态持久化。
- Production、Live Preview 和 Demo 的隔离运行。
- 官方 Usage 页面入口、额度摘要和脱敏诊断复制。

## 非目标

- 预测消息条数、任务消耗或未来额度。
- 使用 Token 数、通用 credits 余额或本地历史自行换算官方额度。
- 自动购买 credits、自动消费重置卡或提供任何账户写入口。
- 读取或修改 Codex 凭据、浏览器 Cookie、网页 DOM、对话或项目代码。
- 自建账户同步服务。
- Electron、WebView 或常驻浏览器内核。
- 用量历史图、多账户、IDE 插件或桌面悬浮窗。

## 安全与隐私边界

- 只允许初始化握手、只读额度读取和接收额度更新通知。
- 不记录或持久化访问令牌、刷新令牌、Cookie、邮箱或完整账户标识。
- 不记录或持久化完整 reset-credit ID、原始认证响应或原始额度响应。
- 原始 wire 数据只在内存中完成 typed parsing；UI 只消费归一化状态。
- opaque 服务端标识不得进入 UI；需要跨重启识别窗口时只保存本地伪匿名键。
- malformed、null、缺失和未知字段不得导致崩溃，也不得静默替换成业务默认值。
- 完整隐私约束见 [隐私说明](PRIVACY.md)。

## 产品验收条件

- 动态窗口名称基于服务端名称或时长生成，不依赖 source slot 的固定含义。
- `usedPercent` 可可靠换算剩余百分比；越界值被限制到显示范围并降低可靠性。
- 缺少百分比的窗口不显示为 0% 或 100%。
- 重置时间按当前 Windows 时区显示；缺失时明确表示未知。
- 重置卡数量严格来自 `availableCount`，缺失时显示不可用，已知为零时显示零张。
- 明细不完整时不得把明细条数当作可用数量；到期摘要只使用有效到期时间。
- 稀疏通知不覆盖未出现字段；无可靠基线时触发完整读取。
- 刷新失败保留最后有效快照，并表现为相应失败或过期状态。
- 提醒只针对可靠百分比，按阈值跨越和周期变化执行跨重启去重。
- Demo 和 Preview 不修改 Production 数据身份、托盘身份或开机启动项。
- 任意 UI 操作都不发送重置卡消费或其他账户写请求。
- 后台不使用高频轮询、持续动画或浏览器运行时。
