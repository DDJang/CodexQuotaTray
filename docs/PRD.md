# CodexQuotaTray 产品需求（Windows / WinUI）

本文只描述 Windows + WinUI 产品。个人使用的 Android 独立 APK 及其后续范围见
[Android Roadmap](ANDROID_ROADMAP.md)。

## 用户问题

Codex 用户需要在不打开官方 Usage 页面、不打断当前工作的情况下，快速了解当前额度、重置时间、可用重置卡和数据状态。查看额度不应要求用户复制认证信息、提供浏览器 Cookie，或承担应用误执行账户写操作的风险。

## 产品目标

- 提供轻量、低干扰的 Windows 托盘额度查看体验。
- 使用本机 Codex App Server 的只读数据，不抓取网页或自行估算额度。
- 准确表达未知、部分可用和读取失败，不把未知值显示成零。
- 刷新失败时保留最后一次有效数据，并标明当前状态。
- 让刷新、提醒、显示和缓存行为可由用户控制。

## 用户可见行为

### 托盘与面板

- 应用常驻通知区域，左键打开或切换额度面板。
- 托盘右键菜单只提供打开面板、设置和退出。
- 面板按服务端实际返回的窗口动态展示，不把内部字段固定解释为某个周期。
- 每个窗口显示名称、剩余或已用百分比、进度、重置时间和倒计时。
- 用户可以识别刷新中、数据过期、离线和读取失败等状态。
- 刷新失败不会清空最后一次有效额度。

### 重置卡

- 服务端明确提供可用数量时展示数量；明确为零时显示零张。
- 有可靠到期信息时展示最早已知到期时间。
- 数量或明细不可靠时显示不可用或部分可用，不根据历史、网页或明细条数猜测。

### 设置、缓存和提醒

- Production 支持开机启动和静默启动；Preview 与 Demo 不修改 Production 启动项。
- 支持刷新模式、网络恢复刷新、剩余/已用显示、时间格式、主题和额度缓存设置。
- 支持剩余 50%、20%、10% 阈值提醒及额度周期重置提醒。
- 非敏感缓存可关闭和清除，只用于快速展示最后已知数据。

## 功能范围

- Windows 10/11 x64 托盘应用。
- 动态额度窗口和重置卡摘要的只读展示。
- 自动、固定间隔和仅手动刷新模式。
- 设置、非敏感缓存和提醒去重。
- Production、Live Preview 和 Demo 的隔离运行。
- 官方 Usage 页面入口、额度摘要和脱敏诊断复制。
- 可选的手机 Token 同步：从本机 Codex session history 只读聚合 Token 数字，并仅在用户开启时通过私人局域网提供带密钥鉴权的只读接口。

## 非目标

- 预测消息条数、任务消耗或未来额度。
- 根据 Token、余额或本地历史换算官方额度。
- 购买 credits、消费重置卡或提供其他账户写入口。
- 读取 Codex 凭据、浏览器 Cookie、网页内容、对话或项目代码。
- 自建账户同步服务、Electron、WebView 或常驻浏览器内核。
- Windows 端用量历史图、多账户、IDE 插件或桌面悬浮窗。

## 产品验收

- 未知额度和重置卡信息不会显示成零。
- 重置时间按当前 Windows 时区显示，缺失时明确表示未知。
- 刷新失败保留最后有效数据，并显示相应状态。
- 提醒不会在同一额度周期内重复轰炸用户。
- Demo 和 Preview 不影响 Production 数据、托盘身份或开机启动项。
- 任意 UI 操作都不会消费重置卡或发送其他账户写请求。
