## Android

### Liquid Glass 交互与视觉

- 全面升级底部导航、操作按钮、分段选择器和开关的 Liquid Glass 交互，统一按压、拖拽、回弹和触感反馈。
- 优化主页、设置页、二级页和 About 页的 backdrop 采样、滚动渐变模糊与页面过渡，提升快速滚动和回弹时的连续性。
- 改进设置页分段选择器的尺寸、文字对齐、边缘溢出和选中状态表现，避免玻璃形变被卡片边界截断。
- 限制操作按钮的最大拖拽形变，保留短距离拖动的液态反馈，同时避免长距离拖动无限拉伸。

### 额度与 Token 数据

- 新增 OpenAI 与 Windows 数据源优先级设置，支持在额度和 Token 数据之间保持一致的来源选择与回退行为。
- 改进多数据源刷新失败时的回退判断，区分暂不可用、网络错误和服务端错误，尽量继续使用可用来源。
- 新增 Token 使用热力图及液态 Tooltip 展示，优化选中定位、拖动浏览和弹出层与网格之间的间距。
- 优化额度环、卡片高光和 Token 统计页面的视觉连续性。

### 设置与页面细节

- 优化账号与配对、更新设置及 About 页面中的状态文案和链接展示。
- 改进页面背景录制与顶部渐变模糊，使正文、卡片和分隔线滚动经过玻璃控件时保持一致效果。
