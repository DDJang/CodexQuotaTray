# Security Policy

## Supported Versions

Security fixes are provided for the latest released version of CodexQuotaTray.

| Version | Supported |
| --- | --- |
| Latest release | ✅ |
| Older releases | ❌ |

Users are encouraged to update to the latest available Windows or Android release before reporting an issue.

## Reporting a Vulnerability

Please do not report security vulnerabilities through public GitHub Issues, Discussions, or pull requests.

Use GitHub's **Private vulnerability reporting** feature instead:

1. Open the **Security and quality** tab of this repository.
2. Select **Advisories**.
3. Select **Report a vulnerability**.
4. Provide as much information as possible about the issue.

When possible, include:

- The affected platform (Windows or Android).
- The affected CodexQuotaTray version.
- Steps required to reproduce the issue.
- The expected and actual behavior.
- The potential security impact.
- Any relevant logs, screenshots, or proof-of-concept information, with sensitive data removed.

Please allow reasonable time for investigation and remediation before publicly disclosing the vulnerability.

## Scope

Security reports may include issues involving:

- CodexQuotaTray Windows or Android clients.
- OAuth credential handling.
- Windows-to-Android LAN synchronization and pairing.
- Local data storage or sensitive-data exposure.
- Automatic update mechanisms.
- Release artifacts, installers, or integrity verification.
- Privilege, code execution, or authentication vulnerabilities.

General bugs, feature requests, and non-security issues should be reported through the normal GitHub Issues page.

## Security Updates

Confirmed vulnerabilities will be evaluated and, when appropriate, fixed in a future release. Security advisories may be published after a fix is available.
